# MAKE A VARIABLE

## Goal

Learn what a variable is as well as how to create one in python

---

**Variable:** A variable is a letter, symbol, or word that represents something else

**Common Variable Types:**

	Integers (int): represents any whole number

	Strings (str): represents any string of words

	Booleans (bool): represents a true/false statement

---

We use variables frequently in python and write them using the following syntax:

[letter, symbol, or word]: [type] = value

For example:

_numberOfRoations: int = 1_

* `numberOfRotations` is the word used to represent the variable
* `int` is the type of data that is stored in the variable
* `1` is the integer value assigned to the variable

_foodType: str = “Fruit”_

* `foodType` is the word used to represent the variable
* `str` is the type of data that is stored in the variable
* `Fruit` is the text(aka string) value assigned to the variable

_isOn: bool = True_

* `foodType` is the word used to represent the variable
* `str` is the type of data that is stored in the variable
* `Fruit` is the text(aka string) value assigned to the variable

---

You can name a variable almost anything that you want. However, when you name variables in python, your variable names may not include minus operator signs, special characters, or spaces. If you want to make a variable name with multiple words, you have two options. Most people prefer using camel case, which in code would look like camelCase, or you can use snake case, which uses underscores, like snake_case.

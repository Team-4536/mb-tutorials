# how to make a tutorial
step by step guide to create a tutorial

### 1. create a new file
<img width="3787" height="1727" alt="Screenshot 2026-10-27 164911" src="https://github.com/user-attachments/assets/75f61892-c3d6-48d1-be7a-f921f57ce68e" />

_press 'code' and then 'new file'_
***
### 2. name it accordingly and add '.md' (should say 'mb-tutorials/<name>.md in main')
<img width="533.5" height="71" alt="Screenshot 2026-10-27 164951" src="https://github.com/user-attachments/assets/84bf0fae-825f-408f-8444-dfd23c36b2fa" />

_name the file according to the tutorial you're creating._
***
### 3. commit to main

_press the green commit button to the right and then press commit to main. this will save the file and allow you to exit without deleting it._
***
### 4. copy the code in the 'readme.md' file in '00_blankTutrial' folder 
<img width="3782" height="1465" alt="Screenshot 2026-10-27 165238" src="https://github.com/user-attachments/assets/cff004ce-1af6-4ad6-b55f-950d234bb057" />

_open the file 'readme.md' and then press 'code'. from here highlight all of the code and copy (ctrl+c)._
***
### 5. paste the code 
<img width="3790" height="1690" alt="Screenshot 2026-10-27 165254" src="https://github.com/user-attachments/assets/a015e23a-5911-4ff0-9ac7-b09fbf680cb7" />

_going back to your file, edit, and then paste code (ctrl+v)_
***
### 6. edit it to fit your tutorial 

_using the copied guide for formatting, write out your tutorial. make sure to include some way that shows their learning (eg: Challenge propblem)_
***
### 7. commit to main and update GitHub issue from 'in progress' to 'to be reviewed' 

_once completed commit and update GitHub for it to be reviewed and tested_
***

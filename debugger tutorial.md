the dots are beak points that stop the program while its running.
when the program is stopped, it shows the actions of a line of code or a called back line of code
 (variables, inits, prints, if/else, etc).
 to use debugger, press the run button in between the "go" button and the three dots on the top left.
 or press the triangle with a bug on the left bar under the github branch button.
 once the tab pops up, press run debugger.

 when debugging, a bar will appear on the top near the file tabs, there are six buttons
 the two lines/line and triangle pause and resume the program
 the dot with the arrow going over it in a half circle runs the current line of code and stops on the second line.
 the dot with the arrow pointing down to it executes the current line of code. (Pretty much the same as the last one)
 the dot with the arrow pointing up away from it runs the rest of a function and returns to the code that called it.
 the green arrow that goes in a circle restarts the program.
the red square terminates the program at any point you press it.

 to place break points, go to the line that you want to stop at, go to the left hand side of that line, and press to place a dot.

# GitHub: what is it and how to use it 

GitHub is a website that allows us to share and organize programming code 

### team GitHub 

our team GitHub has all of our code and issues (issues are tasks that need to be done or have been completed) 

from here you will be able to participate with the team on robot code, keep reading to learn more 

### using code on GitHub 

when programming for our team: 
copy the link given when you tap '<> code ' in the designated repository ---> go to VS code, press 'clone git repository...', and then paste and press enter. 
you will have to save it to your files. 

locate this icon <img width="50" height="56.38" alt="Screenshot 2026-11-10 165544" src="https://github.com/user-attachments/assets/16107728-6c81-4510-a2ec-7ef6cf9b1ddf" /> and press the 3 little dots besides where it says 'changes' and create a branch.
 
from this branch you can edit and change the program as see fit without messing up the main program. 

### issues 

issues are located in projects and repositories 

issues are tasks, they have names, descriptions, and other important information. when looking for something to do, locate the issues and assign yourself a task and work with others who might already be working on that issue. 

issues allow everyone to understand what needs to be done, what has been done, who's doing what, and the progress of the task. they are very important for our team and its important to mot only use them but continue to update them constantly. 

### challenge

now that you have a understanding of GitHub and how to use it, locate a project, assign yourself to an issue, read the description, and complete it. 
feel free to ask your peers, captains, or mentors for any support or help if needed. 
if someone's already assigned to the task you want to do, no worries, just add yourself to it and work together.

**`WELCOME TO MINUTEBOTS TUTORIALS!`**

If this is your first time, start here:

1. Click the green button that says code and then copy the link that says HTTPS

![alt text](image.png)

2. Go to VS Code. Open a new window in VS Code and then press the blue button that says "clone repository"

![alt text](image-1.png)

3. Paste the link that you copied into the top bar that will pop up and then press enter

![alt text](image-2.png)

4. A window to select a file will pop up. Double click on the tab that says Windows C:

![alt text](image-3.png)

4. In Windows C:, create a new folder by pressing the new folder button and name it yourNameRepos (no spaces, no punctuation).

![alt text](image-4.png)

5. Double click the folder you just made to go inside it. After that create another folder within that one called yourNameTutorials.

6. click once on the yourName-tutorials file so it is highlighted and then press the "select as repository destination" button

![alt text](image-5.png)

7. click the sidebar button in VS Code that looks like a tree

![alt text](image-6.png)

8. now you should be in source control. Press the three white dots in the corner, hover your mouse over the option that say branch, then select "Create Branch..."

![alt text](image-7.png)

9. Finally, in the bar at the top that appears, type in "yourName-practice" and then press enter

![alt text](image-8.png)
